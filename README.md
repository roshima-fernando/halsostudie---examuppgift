## halsostudie---examuppgift

#### Analys av hälsodata i Jupyter Notebook (`health_study.ipynb`).

- Python-version: 3.14.7
- Paket: se `requirements.txt`
- Del 1 finns i branchen `del1`, del 2 i branchen `del2`.

## Kom igång

```bash
# Klona projektet
git clone https://github.com/roshima-fernando/halsostudie---examuppgift.git
cd halsostudie---examuppgift

# Skapa och aktivera virtuella miljö
python m venv .venv
# Windows PowerShell
.venv\Scripts\Activate

# macOS/Linux
# source .venv/bin/activate

# instalera beroenden
python -m pip install -r requirements.txt
```
